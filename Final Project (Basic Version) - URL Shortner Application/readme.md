# URL Shortener Web Application

A simple URL Shortener built using Flask, HTML, CSS, Bootstrap, and SQLAlchemy ORM.

## Features
- Shorten long URLs
- Copy shortened URLs with one click
- Store URLs in database
- View URL history
- Redirect to original URL
- URL validation

## Tech Stack
- Flask (Python)
- SQLite
- SQLAlchemy ORM
- HTML, CSS, Bootstrap

## How to Run
1. Install dependencies
2. Run app.py
3. Open browser and use the app
